# Восстановление пароля

Для восстановления пароля перейдите по <a href="https://e.mail.ru/password/restore/">ссылке</a>.<br>
В форме нужно вместо выбора ящика из списка написать e-mail полностью.

# Условия восстановления пароля

Пароль по ссылке выше можно восстановить, если к Вашему аккаунту привязан номер телефона и/или резервный адрес электронной почты. Если привязки нет, то восстановление доступно только вручную через администратора.

У любого, у кого есть почта на chivarzin.ru есть аккаунт mail.ru с таким же e-mail, но этот аккаунт имеет меньше возможностей, чем обычный аккаунт mail.ru.
